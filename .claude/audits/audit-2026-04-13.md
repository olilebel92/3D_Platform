## ⚠️ Design Smells & Runtime Risks

1. **`UI_FPSCounter:34` — NullReferenceException when `panel` is unassigned**
   `panel.SetActive(!panel.activeSelf)` is executed before the null guard at line 39. If the Inspector field `panel` is left blank, pressing F3 throws immediately.

2. **`Fireball:129` — `ComputeRawDamage()` fallback runs server-side with null singletons**
   If `precomputedDamage == 0` (e.g., a fireball not spawned via `SpellCaster`), the fallback reads `ExperienceManager.Instance` and `SkillTreeManager.Instance`. On the server those are null → damage silently falls back to `baseDamage × 1.0`, producing wrong values with no error.

3. **`HealingWave:110` — `FindGameObjectsWithTag("Player")` inside every channel tick**
   Called from `ChannelTick()` at `channelTickRate` (default 0.5 s) while channeling. This allocates a new array every half-second on the server. In longer sessions this is measurable GC pressure.

4. **`WaveManager:139` — `FindGameObjectWithTag("Player")` in `Start()` races player spawn in MP**
   In multiplayer `PlayerSpawner` spawns players asynchronously after the scene loads. `WaveManager.Start()` may run before any player exists, leaving `playerTransform = null`. The ring-spawn fallback then centres enemies on `WaveManager.transform.position`, which could be anywhere in the scene.

5. **`MovementTutorialTrigger:87-94` — `WaitForXPManager()` has no timeout**
   The coroutine `while (ExperienceManager.Instance == null) yield return null;` runs forever in any scene where no player spawns (e.g., a test scene, a dedicated server). Needs a max-iteration guard or a scene-type check.

6. **`ExperienceManager` calls `SkillTreeManager.Instance.AddSkillPoint()` directly in `TriggerLevelUp()`** instead of letting SkillTreeManager subscribe to the existing `OnLevelUp` event. This means `SkillTreeManager` must always be present or a warning log fires — and any new system that should react to level-up must be wired here too.

7. **`LobbyChatManager.OnSendClicked()` — indentation break at line 81**
   `string senderName = GetLocalPlayerName();` has inconsistent indentation — cosmetic but signals an unreviewed edit.

## 🚨 Priority Fix List (Top 5)

### 1. UI_FPSCounter: NullRef on F3 toggle
- **Risk:** `panel.SetActive(...)` at `UI_FPSCounter:34` executes before the null guard below it. Any Inspector-configured scene with `panel` unassigned will throw a `NullReferenceException` every frame F3 is pressed.
- **Fix:** Move the null guard above the `SetActive` call, or consolidate: `if (panel != null && Keyboard.current.f3Key.wasPressedThisFrame) panel.SetActive(!panel.activeSelf);`

---

### 2. Fireball: Silent wrong damage when `precomputedDamage == 0` on server
- **Risk:** `Fireball:129` falls back to `ComputeRawDamage()` which reads `ExperienceManager.Instance` and `SkillTreeManager.Instance` — both null on the server. Damage becomes `baseDamage × 1.0` with no log. Any fireball not spawned via `SpellCaster.SpawnProjectileServerRpc` (editor test, scripted event) uses wrong damage silently.
- **Fix:** Add an `Assert.IsTrue(precomputedDamage > 0, "[Fireball] precomputedDamage not set...")` in `OnNetworkSpawn` so the bug surfaces immediately. Alternatively, remove the fallback entirely since it's invalid server-side.

---

### 3. HealingWave: `FindGameObjectsWithTag` allocation every channel tick
- **Risk:** `HealingWave:110` searches all scene objects with a `"Player"` tag on every `ChannelTick()` call (default every 0.5 s). This allocates a new `GameObject[]` on the server and adds GC pressure across extended sessions.
- **Fix:** Cache the player list as a `static List<GameObject>` that `PlayerController.OnNetworkSpawn`/`OnNetworkDespawn` registers/unregisters from. HealingWave reads from the cache instead.

---

### 4. WaveManager: `playerTransform` null in multiplayer due to spawn-order race
- **Risk:** `WaveManager.Start()` calls `FindGameObjectWithTag("Player")` before `PlayerSpawner` has asynchronously placed players. `playerTransform` stays null for the entire session, causing all ring-spawns to orbit `WaveManager.transform.position` (likely the scene origin).
- **Fix:** Expose a `public void RegisterPlayer(Transform t)` method on `WaveManager` and call it from `PlayerController.Start()` / `OnNetworkSpawn()`. First registered player sets `playerTransform`; subsequent ones append to a list for multi-player ring distribution.

---

### 5. MovementTutorialTrigger: Infinite coroutine with no timeout
- **Risk:** `WaitForXPManager()` polls `ExperienceManager.Instance == null` every frame with no exit condition. In any scene without a player (dedicated server, test build, editor play without a prefab) the coroutine runs for the entire session, burning CPU on a tight per-frame null check.
- **Fix:** Add a frame cap: `int attempts = 0; while (ExperienceManager.Instance == null) { if (++attempts > 600) { Debug.LogWarning("[MovementTutorialTrigger] ExperienceManager not found after 10s — aborting."); yield break; } yield return null; }`
